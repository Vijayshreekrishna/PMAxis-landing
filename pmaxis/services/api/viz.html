Data Model Reference
How data flows through PMAxis

Understand where each piece of data comes from before you build on it.

TradesClickHouse

Source: Polymarket WebSocket feed

Fields: trade_id, market_id, token, price, size, side, timestamp, tx_hash

Key: tx_hash links to onchain_trades for wallet addresses

Retention: Permanent

Onchain TradesClickHouse

Source: Polygon blockchain (ERC-1155 settlements)

Fields: tx_hash, maker, taker, token_id, amount, timestamp

Join: tx_hash = trades.tx_hash to enrich trades with wallets

Retention: Permanent

Price HistoryClickHouse

Tables: price_history_1m, price_history_1h

Fields: market_id, timestamp, open, high, low, close, volume

Use for: charting, backtesting, OHLCV analysis

Retention: Permanent

OrderbookRedis

Source: Polymarket CLOB, updated real-time

Fields: bids[], asks[] each with price + size

Use for: market making, spread analysis, depth charts

Retention: In-memory only (latest state)

MarketsPostgres + Redis

Source: Polymarket Gamma API (crawled continuously)

Fields: market_id, question, status, category, price, bid, ask…

Live prices: Redis (updated by WebSocket processor)

Retention: Permanent

SignalsRedis

Source: Processor hub (computed from price/trade feed)

Types: momentum, volume_spike, spread_alert…

Endpoint: GET /v1/markets/{id}/signals

Retention: In-memory only (recent signals)
